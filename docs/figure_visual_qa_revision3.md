# Revision 3 图表视觉核查记录

## 第一次核查：Figure 3 与 Figure 4

**Figure 3（合成标签反转敏感性）**展示0%、5%、10%和20%四个水平，坐标、三种子标准差误差条、合成扰动边界说明与图例均可读。两条优化器曲线在给定精度下几乎重合，这是数据结果而不是图形错误；为避免后绘制曲线掩盖前一条曲线，已改为Adam实线圆点、AdamW虚线方点。纵轴范围与标注呈现噪声水平带来的实质性下降，不将其作为等价性或因果检验。

**Figure 4（概率质量）**采用一个并列的Brier/ECE汇总面板和一个清洁训练条件下的可靠性曲线面板。三个变体使用相同的24,306个测试目标；脚注明确ECE是十个固定宽度分箱，Brier与ECE均为描述性概率质量指标，不是显著性检验。条形图的不同量级容易阅读，可靠性曲线的对角线基准和坐标轴标签明确。

后续核查将检查Figure 1、Figure 2和探索性预算Figure A1，以及插入DOCX后的缩放和分页。

## 第二次核查：Figure 1 与 Figure 2

**Figure 1（统一next-response基线）**的三根柱形、95%学生簇bootstrap误差条、具体AUC标签及底部协议说明均清晰可见。图注明确神经基线柱为seed 20260822的单次运行，因此不会将该区间误读为三种子区间；三种子汇总仅在Figure 2和对应结果表中报告。

**Figure 2（三种子消融）**的纵轴从0.70开始，满足前一轮关于不视觉放大极小波动的要求。三个种子散点、均值横线、三个变体标签和“n=3 descriptive, not an equivalence test”脚注完整可读。图中没有显著性符号、排名箭头或“无效应”措辞，因此不超出该设计的统计证据范围。

## 第三次核查：Figure A1 与修正后的 Figure 3

**Figure A1（探索性延长预算）**清楚标出第8轮主分析资源上限（虚线）、三条验证AUC轨迹和各种子在20轮内的验证选点（星标）。底部说明明确测试集仅在每个种子完成验证选择后评估一次，且该事后扩展不替换主分析。图中不含测试AUC曲线，避免错误地暗示多次测试集选择。

**Figure 3修订版**中Adam为蓝色实线圆点，AdamW为橙色虚线方点。两条线在所有四个噪声水平基本重合，这一可见重合忠实呈现观测结果，同时虚线与符号使两个系列在局部仍可识别。误差条与说明文字保留，图形满足插入主稿的可读性要求。
