# GitHub 分级存储与数据边界

本项目采用三层存储，而不是以公开/私密权限替代数据使用许可。**数据条款优先于仓库可见性**：ASSISTments匿名学生记录及其可逆派生物不进入任何GitHub仓库，包括私有仓库。

| 层级 | 位置 | 允许工件 | 明确排除工件 | 目的 |
|---|---|---|---|---|
| 公开可复现层 | `JustinZheng161/kt-slm-audit-public` | 运行代码、数据获取与校验说明、依赖说明、聚合JSON、聚合元数据、图表、许可证和安全的实验/图表生成日志 | 原始数据、逐学生结果、ID、split、序列、逐行预测、NPZ、模型权重、审稿意见与可交付文章DOCX | 允许具备数据访问资格的读者自行取得来源并复现聚合结果 |
| 私密文章审计层 | `JustinZheng161/kt-slm-audit-private-archive` | 公开层内容的审计快照、主稿DOCX、补充信息DOCX、审稿回复、审稿意见、修改矩阵、机器/视觉验收记录、论文生成脚本 | 与公开层相同的所有受控数据及可逆派生物；网页源码和网页构建产物 | 保存文章修订轨迹、逐条审稿回应和可交付文件 |
| 本地受控层 | `/home/ubuntu/controlled-research-data/kt-slm-audit/` | 原始官方下载、学生级序列、划分、逐学生/逐交互预测和临时模型工件 | 所有远程仓库同步、网页目录和交付附件 | 仅在适用的数据使用条款允许的本地受控研究环境中运行实验 |

## 统一阻断规则

所有待同步路径在暂存前必须拒绝以下模式：`*.csv`、`*.tsv`、`*.parquet`、`*.feather`、`*.npz`、`*.npy`、`*.pt`、`*.pth`、`*.ckpt`、`*.onnx`、`private_data/**`、`controlled-research-data/**`、`client/**`、`dist/**`、`node_modules/**`、`.env*`。路径名未命中不代表安全：只上传明确列入本清单的聚合结果和元数据。

## 发布前复核

每次同步前和推送后均需审查暂存清单或远程树。公开库必须含有数据获取链接、校验值和用途限制；私密库必须含有文章交付物与验收记录；两个库均不得出现学生级或网页文件。任何新的数据版本、序列化格式或模型工件都应默认归为受控层，除非经过独立的许可证和可逆性审查。
